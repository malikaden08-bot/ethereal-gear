# Ethereal Gear — Apple iOS 26 Liquid Glass Digital Agency & SaaS Platform

Ethereal Gear is an ultra-luxurious digital marketing agency website and interactive SaaS platform built with **Apple iOS 26 Liquid Glass design system**, real-time **3D WebGL graphics** powered by React Three Fiber, **Supabase Authentication & Role-Based Access Control (RBAC)**, and a **100% No-Code Admin CMS Dashboard**.

---

## 🌟 Key Features

- **Apple iOS 26 Liquid Glass Architecture:** Specular highlights, backdrop blurs, glass reflections, and physical lens interactions.
- **Cinematic 3D WebGL Canvas:** Interactive physical transmission shaders, floating geometric shapes, and camera physics.
- **Supabase BaaS & Auth:** Session management, JWT security, and RBAC matrix supporting `Admin`, `Editor`, `Marketing Manager`, `Super Admin`, and `Viewer`.
- **100% No-Code Admin CMS Dashboard:** 15 comprehensive tabs for managing hero content, 3D WebGL params, service offerings, portfolio case studies, pricing tiers, client reviews, blog CMS articles, CRM lead inquiries, media library uploads, SEO meta tags, theme customizer tokens, analytics telemetry, staff roles, and audit logs.
- **Marketing Integrations:** GA4, Google Tag Manager, Meta Pixel, WhatsApp Business floating widget, Calendly booking modal, Resend email dispatch, and Cloudinary responsive image transformations.
- **Motion & Scroll Physics:** Smooth spring physics scroll indicator, section reveals, and blur-to-focus text reveals.
- **SEO & Performance Engine:** XML Sitemap, `robots.txt`, Open Graph, Twitter Cards, and JSON-LD Schema markup.

---

## 🛠️ Technology Stack

- **Frontend Core:** React 19, TypeScript, Vite
- **Styling & Tokens:** Tailwind CSS v4, Vanilla CSS Custom Variables
- **Animations & 3D:** React Three Fiber, Drei, Three.js, Framer Motion
- **Backend & Auth:** Supabase, PostgreSQL, Row-Level Security (RLS)
- **Email & Communications:** Resend API, WhatsApp Business, Calendly
- **Linter & Build Tools:** Oxlint, TypeScript Compiler (`tsc -b`)

---

## 🚀 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/malikaden08-bot/ethereal-gear.git
cd ethereal-gear

# Install dependencies
npm install

# Copy environment variables
cp .env.example .env.local

# Run dev server
npm run dev
```

---

## 🔒 Production Build & Deploy

```bash
# Run Oxlint linter audit
npx oxlint

# Run strict TypeScript compilation check
npx tsc -b

# Production build
npm run build
```
